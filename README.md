# desktop-snow-site

Лендинг приложения **Desktop Snow** — «Новый год уже здесь. Прямо на твоём рабочем столе».

Дизайн-система: **[DESIGN.md](DESIGN.md)** (skill `web-design`, Phase B) + референс **raycast.com**: обсидиан `#070709`, панели `#0D0E12` со стеклянной кромкой `1px rgba(255,255,255,.08)` и верхним бликом, металлические заголовки (Manrope 800, `#FFFFFF→#A1A1AA`), сине-красное aurora-свечение.

Структура:
- **Nav** — логотип-снежинка, якоря, RU/UA/EN, «Скачать» (fixed, blur 14px, scrolled-state).
- **Hero** — H1 с word-stagger, lead, белая CTA на GitHub Releases + GitHub, техстрока, 4 цвета снега (как в приложении), витрина 1080px с реальным скриншотом `screenshots/settings-snow.png` и **живым сугробом на верхней кромке** (снег реально оседает; клик/тряска стряхивает; `Ctrl+Alt+S` — тает).
- **Bento 7/5 + 5/7** — DWM-привязка, «Пауза за 0 мс» (гигантская типографика), живой мир, глобальные хоткеи с физическими `kbd`.
- **Интерфейс** — табы «Общие / Снег / Украшения» одной строкой + крупные реальные скриншоты приложения (без макетов и заглушек).
- **CTA + футер** в одну строку.

Снегопад: Canvas 2D, 3 слоя глубины, ветер, отталкивание от курсора, 140/70 частиц, пауза на скрытой вкладке, полное выключение при `prefers-reduced-motion`. Хоткей `Ctrl+Alt+S` — вкл/выкл, как в приложении.

Технически: без сборки и зависимостей (`index.html` + `style.css` + `app.js`), только Google Fonts; кэш-бастинг `?v=N`; анимации только opacity/transform; ноль WebGL.
