# desktop-snow-site

Лендинг приложения **Desktop Snow** — «Новый год уже здесь. Прямо на твоём рабочем столе».

Дизайн по референсу **raycast.com**: обсидиановый фон `#070709`, графитовые панели `#0D0E12` со стеклянной кромкой и световым бликом сверху, металлические заголовки (белый→серый вертикальный градиент, Plus Jakarta Sans 800, трекинг −0.035em), сине-красное «северное сияние» за витриной.

Структура:
- **Hero по центру** — заголовок, подзаголовок, две кнопки (белая «Скачать для Windows» + тёмное стекло «Потрясти окно»), техстрока, переключатель цвета снега (Белый / Ледяной синий / Новогодний красный / Золотой — управляет реальным снегопадом страницы).
- **Витрина** — сине-красное свечение, живое окно Windows 11 (Mica): таскается за шапку, снег едет попиксельно, при рывке разлетается, курсором смахивается, чип «Режим игры · F11» в шапке прячет снег за 0 мс. Сугробы объёмные (градиент + контактная тень + блики).
- **3 крупные витрины**: «Снег, который чувствует каждое окно» (канвас с DWM-привязкой и паузой под рамкой Lightshot + хоткеи Ctrl+Alt+S/D в стиле Raycast), «Лепи снеговиков и запускай поезд» (песочница: катай комы → снеговики; поезд с физикой разбрасывает и они восстанавливаются; ёлка с гирляндой), «Нативный интерфейс в стиле Windows 11» (реальные скриншоты `screenshots/settings-*.png`, табы Общие/Снег/Украшения в одну строку).
- Финальный CTA «Готов к Новому году?» на сине-красном градиенте, футер в одну строку, RU/UA/EN.

Технически: без сборки и зависимостей (`index.html` + `style.css` + `app.js`), `prefers-reduced-motion`, пауза анимаций на скрытой вкладке, кэш-бастинг `?v=N`, тёмный скроллбар.
