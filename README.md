# desktop-snow-site

Лендинг приложения **Desktop Snow** — «Новый год уже здесь. Прямо на твоём рабочем столе».

Статичный сайт без сборки и зависимостей: `index.html` + `style.css` + `app.js` (+ `screenshots/`).

Что внутри:
- **Живой hero** — макет рабочего стола Windows 11: окно «Блокнот» с объёмным сугробом на шапке, снег на панели задач; окно таскается мышью (снег едет попиксельно), при рывке — разлетается, курсором смахивается; кнопки «Потрясти окно» и «Режим игры / F11» (мгновенная пауза за 0 мс).
- **Мини-переключатель снега** как в самой программе: режим Снег/Конфетти и 4 фирменных цвета (белый, ледяной голубой, тёплое золото, нежно-розовый) — управляют реальным снегопадом на странице.
- **Асимметричный бенто из 4 карточек** с живыми канвас-визуализациями: DWM-привязка и пауза под рамкой скриншота (Lightshot/ShareX/«Ножницы»), песочница лепки снежков и снеговиков, мир с поездом (сбивает снеговиков — те собираются обратно) и ёлкой с 4 темами (Классика, Иней, Леденцы, Золотая ночь), превью **реальных скриншотов** настроек (`screenshots/settings-general|snow|decor.png`) с переключением вкладок.
- Компактная полоса установки (ZIP → Распакуй → `DesktopSnow.exe`), RU/UA/EN, `prefers-reduced-motion`, пауза анимаций на скрытой вкладке, кэш-бастинг `?v=N`.

Шрифты: Unbounded (заголовки), Inter (текст), JetBrains Mono (техтеги). Палитра: зимняя ночь `#060A12/#0B1220`, Mica-карточки `rgba(20,28,46,.65)` + `blur(20px)`, золото `#FBBF24`, лёд `#38BDF8`.
